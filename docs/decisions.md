# Decision log

**TL;DR**

- One row per decision that applies to the whole team and is not an ADR. Decisions about a single issue go on the issue; architecture and lasting trade-offs go in [docs/adr](adr/README.md).
- The agile coach adds rows after each meeting, batched in one pull request per iteration, as [ADR-0005](adr/0005-planning-and-flow.md) decides.
- The repository is public: a row says that a decision was made and where the details live, never details of a vulnerability, an incident with customer data, or anything that could not go in a public issue. The [data policy](ai/data-policy.md) applies.
